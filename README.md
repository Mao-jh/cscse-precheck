# 留服认证·拒批风险预审 · 集成支付 AI Skill

> 对话里直接问，出一份带编号依据的风险预审报告。按次付费（¥3.99/次），**无订阅**；
> 已内置**支付宝 AI 收（402）完整支付能力**，装完即用，无需另行安装任何官方支付组件。

## 这是什么

输入留学画像（院校与国家、专业学制、网课情况、出入境记录、前置学历、学位状态），返回认证风险报告：风险等级与置信度、逐条雷点（对号口径条目编号+相似拒批/通过案例编号+整改建议）、高频拒因对照（院校名单、出入境比对、网课红线、证明信限制、前置学历核验）、认证流程要点（360元、官方无法加急、必须本人办理）、拒批后果与补救路径。

## 安装（一句话）

```bash
git clone https://github.com/Mao-jh/cscse-precheck.git ~/.claude/skills/cscse-precheck
```

其他支持 skills 目录的 AI 客户端同理：把本仓库克隆/复制到对应 skills 目录即可。

## 怎么用

安装后在对话里直接问，例如：

- 「留服认证会被拒吗」
- 「一年制硕士出境多少天才够」
- 「中途回国影响认证吗」

流程：Agent 收集必要信息 → 调用后端 → 返回 402 待支付账单 → 内嵌支付流程拉起
**支付宝官方 `alipay-bot` CLI**（npm 包 `@alipay/agent-payment`，首次使用经完整性校验后安装）→
你用支付宝扫码付款 → 服务端验付 → 自动返回报告。支付判定以服务端校验为准，支付由用户本人确认。

## 定价

- **¥3.99 / 次**，按次收费，无订阅、无隐藏费用；与支付宝服务登记价完全一致。
- 收款走支付宝 AI 收（A2M/402 协议）：调用 → 402 账单 → 支付宝授权 → 验付 → 履约。

## 你会拿到什么

- `risk_level`：低 / 中 / 高，附置信度
- `hits[]`：逐条风险点，含**编号化依据**（口径条目 CS / CX + 相似案例编号），可信度可核验
- 高频拒因对照（院校名单/出入境比对/网课红线/证明信限制/前置学历核验）、认证流程要点与补救路径
- 固定免责声明：本报告为**风险预审**（顾问位），不构成「必过/必拒」类保证
